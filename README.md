# Lumbar Brace Instruction

Patient-facing landing page in Russian: how to choose, wear, and use a lumbar support brace.

## GitHub Pages

Upload this folder contents to a GitHub repository:

- `index.html`
- `assets/`

Then enable GitHub Pages:

1. Open repository `Settings`.
2. Go to `Pages`.
3. Choose `Deploy from a branch`.
4. Select branch `main` and folder `/root`.
5. Save.

The public page will be available at:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```
